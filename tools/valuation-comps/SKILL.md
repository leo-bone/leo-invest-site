# Valuation Comps（可比公司估值）

一个让 coding agent 执行**可比公司分析（trading comps）**的可复用 skill。
设计哲学同 Zara Zhang 的 `frontend-slides`：代码只是表达媒介，**能复用、能复现**才值得做。
本 skill 不预测点位，只给"市场现在愿意为这类生意付多少倍"的相对锚，并与绝对估值互相印证。

## 何时使用
- 判断某标的相对同行的估值贵贱；
- 给投行/投资/研究场景快速产出标准化 Comps 表；
- 作为 DCF /  precedent transactions 的交叉验证。

## 八步流程（必须按顺序跑完）

1. **定标的**：明确分析对象（A股/港股/美股代码或公司名）。确认视角：买方（要不要买）还是卖方（该卖多少）。
2. **选 peer**：按"业务同质 + 规模可比 + 市场相同"三维筛选，**不按行业标签硬凑**。目标 3–8 家。记录筛选逻辑。
3. **取倍数**：至少取 EV/Revenue、EV/EBITDA、P/E；成长股补 EV/Gross Profit，金融股用 P/B/P/E。明确每个倍数的适用前提。
4. **对齐口径**：
   - 用**归一化倍数**（NTM 或 FY+1，即未来 12 个月 / 下一财年口径），不要用 LTM 单点；
   - 剔除一次性损益（重组、减值、投资收益）；
   - 统一资本结构（EV 已含净负债，P/E 不含）。
5. **算中心趋势**：报告**中位数**为主、均值与 25/75 分位为辅。中位数对 outlier 更稳。
6. **做敏感性**：用 25 / 50 / 75 分位倍数 × 标的对应预测指标，给**估值区间**（非单点）。
7. **隐含校验**：把 Comps 结果与 DCF / 交易可比交叉验证；偏离 >20% 必须复盘 peer 选择或口径。
8. **出结论**：明确"相对贵 / 合理 / 便宜"，并给出**触发重估的变量**（不是点位预测）。便宜若无理由 = 价值陷阱，必须说明。

## 数据来源（按优先级）
- **首选 `westock-data` skill**（金融市场结构化数据，覆盖 A/港/美）：拉市值、EV、营收、EBITDA、净利、预测一致预期。
- 备选 `akshare-stock` / `neodata-financial-search`：补 A 股明细与一致预期。
- 兜底 `WebSearch` / `WebFetch`：公司官网 IR、年报、行情页。
- **严禁编造数字**：任何缺失字段标 `N/A` 并注明原因，不在文内填占位假数。

## 输出规范
产出两份：
1. **Markdown 报告**：含筛选逻辑、Comps 表（带中位数/分位）、敏感性区间、结论与重估触发条件。
2. **可选 HTML**：用项目 `assets/style.css` 的同款 `.tbl` 表格样式渲染，便于嵌入个人站点（参考 posts/valuation-comps-guide.html）。

### Comps 表示例（结构，非真实数据）
| 可比公司 | EV/Rev | EV/EBITDA | P/E |
|---|---|---|---|
| Peer A | 4.2x | 14.1x | 22.0x |
| Peer B | 3.6x | 12.8x | 19.5x |
| Peer C | 5.1x | 16.3x | 25.4x |
| **中位数** | **4.2x** | **14.1x** | **22.0x** |

## 边界与免责
- Comps 反映**市场情绪**，不是内在价值；永远与绝对估值交叉验证。
- 倍数差异必须解释来源（增长、杠杆、拐点），不能只报"便宜/贵"。
- 所有结论标注数据日期与来源；投资决策由人负责，本 skill 只产出可复现的分析骨架。
