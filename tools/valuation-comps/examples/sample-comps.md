# 示例报告（脱敏）· valuation-comps

> 以下为流程演示，公司名与数字均已脱敏，仅展示输出结构。

## 标的
某 SaaS 公司（代码：DEMO），买方视角（是否建仓）。

## 1. Peer 筛选逻辑
- 业务同质：通用型 SaaS、订阅收入占比 >80%
- 规模可比：营收 $200M–$1.2B
- 市场相同：美股软件板块
- 入选：Peer A / B / C / D / E（5 家）

## 2. Comps 表（NTM 口径）
| 可比公司 | EV/Rev | EV/EBITDA | P/E |
|---|---|---|---|
| Peer A | 4.2x | 14.1x | 22.0x |
| Peer B | 3.6x | 12.8x | 19.5x |
| Peer C | 5.1x | 16.3x | 25.4x |
| Peer D | 3.9x | 13.5x | 21.0x |
| Peer E | 4.5x | 15.0x | 23.1x |
| **中位数** | **4.2x** | **14.1x** | **22.0x** |
| **25/75 分位** | **3.8x / 4.8x** | **13.2x / 15.7x** | **20.3x / 24.3x** |

## 3. 敏感性（DEMO 预测营收 $420M，EBITDA $84M，净利 $46M）
| 倍数分位 | EV/Rev 隐含 EV | EV/EBITDA 隐含 EV |
|---|---|---|
| 25% | $1.60B | $1.11B |
| 50% | $1.76B | $1.18B |
| 75% | $2.02B | $1.32B |

## 4. 结论
DEMO 当前 EV ≈ $1.30B，对应 EV/Rev 3.1x、EV/EBITDA 15.5x。
- 相对 peer 中位数（EV/Rev 4.2x）**偏便宜**；
- 但 EV/EBITDA 15.5x 已高于中位数 14.1x → **分化信号**；
- 重估触发：若下季净留存率回升且盈利指引上修，便宜成立；若指引下修，便宜是价值陷阱。
- 结论：**合理偏低，需盈利侧确认**，非无脑买入。

> ⚠️ 示例数字为演示，非投资建议。
