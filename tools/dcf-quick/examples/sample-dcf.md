## 5. 下行地板（worst-case，必做）
假设压到最坏：增长下修约 40%（7%/6%/5%/3%/2%）、WACC 上修至 10.5%、终值 g=2%。
| 年 | FCF(亿) | PV(亿) |
|---|---|---|
| 1–5 | … | 130.9 |
| 终值 | 450.5 | 273.6 |
| **EV** | | **404.5** |

权益价值 = 404.5 − 20 = **384.5 亿** → 下行地板 ≈ **¥38.4 / 股**

安全边际 = (38.4 − 50) / 50 = **−23%**（市价高于地板）。

## 6. 结论与仓位上限（由最坏情况倒推）
- 基准情形便宜（+25%），但**下行地板 ¥38.4 < 市价 ¥50**，安全边际为负。
- 纪律：地板 < 1.0× 市价 → **不建仓**。等市价回落至 ¥38 以下，或 worst-case 假设被证伪（增长/利润率实际好于悲观预期）再评估。
- 触发重估变量：① 实际增速是否守住；② WACC 是否随利率下行；③ 利润率是否未压缩。
- 交叉验证：`valuation-comps` 中位倍数若也显示便宜，二者共振才提高置信。
