## 面板（由脚本输出）
**日期**：2026-09-20 ｜ **绿灯数**：1/4

| 变量 | 状态 | 信号 |
|---|---|---|
| 利率 | 🟡 neutral | 实际利率 1.8%，走平 |
| 信用 | 🟢 friendly | HY 利差 320bp，收窄 |
| 盈利预期 | 🟡 neutral | 盈利修正广度 50% |
| 流动性 | 🔴 alert | 央行缩表，基础货币同比转负 |

### 攻守结论：**强制防守（信用/流动性报警）**
- 硬规则触发：信用或流动性警戒 → 强制防守（覆盖绿灯数）。
- 下周关注：流动性是否继续收缩（M2 增速）、信用利差是否跟随走阔。

## 解读
- 表面绿灯 1（仅信用友好），但**流动性已警戒** → 硬规则强制防守，不因为"信用还行"就放松。
- 与 `dcf-quick` 配合：本面板说"守"，即便某标的下行地板 > 1.5× 也不加仓，等流动性警报解除。
- 与 `valuation-comps`：防守期不急着比贵贱，先保住本金。
- 非点位预测；投资决策由人负责。
