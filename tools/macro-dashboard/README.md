# macro-dashboard

宏观四变量周更面板：利率 / 信用 / 盈利预期 / 流动性，输出"攻守开关"而非点位预测。

## 它解决什么
- 把"现在该进攻还是防守"从感觉变成可周更、可回看的仪表盘；
- 与 `dcf-quick` 的纪律咬合：先确认环境允许进攻，再谈买什么、买多少。

## 用法
每周固定时点跑一次：抓取四变量最新值 → 三态判定（友好/中性/警戒）→ 汇总攻守档位 → 输出面板并留痕。

## 攻守规则
4 绿=满格进攻；3 绿=进攻；2 绿=中性；1 绿=防御；信用或流动性任一警戒=直接守。

## 数据来源
`westock-data` / `macro-monitor`（首选）→ `WebSearch` / `WebFetch`（兜底）。严禁编造。

## 免责
四变量是开关不是打分表；结论是判断辅助，决策由人负责。
