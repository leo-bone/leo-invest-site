# 攻守档位规则（硬规则）

绿灯数 = 状态为"友好"的变量个数（共 4 个）。

## 基础档位
| 绿灯数 | 档位 | 含义 |
|---|---|---|
| 4 | 满格进攻 | 四变量全友好，可高仓位 |
| 3 | 进攻 | 三友好，正常偏积极 |
| 2 | 中性 | 一半对一半，均衡仓位 |
| 1 | 防御 | 仅一友好，降仓位 |
| 0 | 全面防御 | 无友好，现金为王 |

## 硬规则（覆盖绿灯数，不可被"我觉得还能扛"推翻）
1. **信用警戒 → 强制防守**。信用是 margin call 前兆，不等绿灯。
2. **流动性警戒 → 强制防守**。流动性是估值分母，收缩即杀估值。
3. 信用 + 流动性同时警戒 → 全面防御（现金为王，不接飞刀）。

## 输出纪律
- 档位只给攻守指引，**不给点位、不给目标价**。
- 任变量 `N/A` → 结论前显式写"X 未知，置信度下降"。
- 与 `dcf-quick` 配合才有"买多少"：本 skill 说"可以进攻"，`dcf-quick` 说"这家地板够不够"；二者都满足才动手。
- 每周 append 快照，信号转折（如从进攻转防御）必须加注原因。
