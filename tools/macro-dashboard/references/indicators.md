# 四变量：具体指标、数据源、阈值

每个变量给"友好 / 中性 / 警戒"三态。阈值随周期漂移，需季度复核；以下为经验默认值。

## 1. 利率（看实际利率，不看美联储嘴）
- 指标：实际利率 = 名义政策/长端利率 − 通胀预期（Breakeven 或 CPI 预期）。
- 方向：**下行友好、上行警戒**（lower_better）。
- 阈值（实际利率 %）：友好 ≤ 1.5；中性 1.5–2.5；警戒 ≥ 2.5。
- 信号：实际利率快速上行 = 杀久期；走平/下行 = 风险偏好修复。
- 数据源：央行、TIPS breakeven、`westock-data`。

## 2. 信用（系统会不会突然缺钱）
- 指标：高收益债利差（HY OAS）、投资级利差、商业票据利差、离岸美元流动性（FRA-OIS、交叉货币基差）。
- 方向：**收窄友好、走阔警戒**（lower_better）。
- 阈值（HY OAS bp，随评级中枢漂移）：友好 ≤ 350；中性 350–500；警戒 ≥ 500（或单周走阔 >50bp 直接警戒）。
- 信号：任一快速走阔 = margin call 前兆，硬规则触发防守。
- 数据源：美联储、ICE BofA、`westock-data`。

## 3. 盈利预期（故事能否兑现）
- 指标：盈利修正广度 = 上调家数 /（上调+下调家数）；前瞻 EPS 修正。
- 方向：**上调友好、下调警戒**（higher_better）。
- 阈值（修正广度 %）：友好 ≥ 55；中性 45–55；警戒 ≤ 45。
- 信号：广度比单看 EPS 增速更提前；转负 = 盈利下修周期开启。
- 数据源：一致预期、`westock-data`、卖方修正数据。

## 4. 流动性（池子里的水涨退）
- 指标：央行资产负债表同比、逆回购规模、广义货币（M2）增速、离岸美元供给。
- 方向：**扩张友好、收缩警戒**（higher_better，但看边际变化）。
- 阈值（以"边际"为准）：友好 = 扩表/增速回升；中性 = 走平；警戒 = 缩表加速或 M2 失速。
- 信号：流动性是风险资产的分母；收缩直接压制估值。
- 硬规则：流动性警戒 → 强制防守。
- 数据源：央行资产负债表、`macro-monitor`。

## 通用
- 任变量 `N/A`（数据缺失）→ 不计入绿灯，结论显式标注置信度下降。
- 阈值每半年复核一次，写入本文件，避免刻舟求剑。
